# Personal Codex Defaults

이 파일은 모든 저장소에 적용되는 개인 기본값만 담는다. 프로젝트 규칙과 명령은 각
저장소의 `AGENTS.md`에서 정의한다.

- 답변과 작업 보고는 `[선호 언어]`로 작성한다.
- 작업 전 현재 저장소와 기존 변경을 확인하고, 사용자의 변경을 보존한다.
- 비사소한 변경은 성공 조건을 먼저 요약하고 작은 단계로 진행한다.
- 확인할 수 없는 명령, API, 파일 구조를 추측하지 말고 저장소에서 근거를 찾는다.
- 변경 후 관련 검사를 실행하고 실행 결과와 남은 위험을 간결하게 보고한다.
- 명시적 요청 없이 commit, push, merge, release, deploy를 수행하지 않는다.
- 저장소의 더 구체적인 `AGENTS.md`가 있으면 그 범위의 프로젝트 규칙을 따른다.
