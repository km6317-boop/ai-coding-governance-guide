# Personal Claude Code Defaults

이 파일에는 모든 프로젝트에 적용할 개인 기본값만 둡니다.

- 답변과 작업 보고는 `[선호 언어]`로 작성합니다.
- 작업 전에 현재 저장소와 기존 변경을 확인하고 사용자의 작업을 보존합니다.
- 비사소한 변경은 성공 조건과 검증 방법을 먼저 정리합니다.
- 확인할 수 없는 명령이나 구조를 추측하지 말고 저장소 파일에서 근거를 찾습니다.
- 완료 전에 관련 검사와 diff 검토를 수행하고 결과와 남은 위험을 보고합니다.
- 명시적 요청 없이 commit, push, merge, release, deploy를 수행하지 않습니다.
- 프로젝트 `CLAUDE.md`와 가져온 공용 지침이 더 구체적이면 해당 범위의 규칙을 따릅니다.

저장소가 `ai-coding-governance-guide` 방식의 제어 평면을 사용하면 루트 `AGENTS.md`를
공통 계약으로, `specs/`를 현재 변경 계약으로, `knowledge/`를 장기 지식으로 구분합니다.
전역 지침에서 프로젝트 규칙을 재정의하거나 AI별 사본을 만들지 않습니다.
